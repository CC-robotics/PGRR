The repository exposes one supported project state: the PGRR final release.
Use these current entry points:

  environment evidence, artifacts, installation, and limitations.
- [`../REPRODUCIBILITY.md`](../REPRODUCIBILITY.md): clean rebuild, release

- [`../CURRENT_STATUS.md`](../CURRENT_STATUS.md): concise authoritative status.

  and provenance.
- [`../paper/claim_evidence_matrix.md`](../paper/claim_evidence_matrix.md):
  claim-to-artifact audit matrix.

Files whose names contain earlier benchmark revisions, old gate reports, or
the special publication-sanitization workflow are retained only as historical
audit evidence. They are not alternative current versions, reproduction
defaults, or valid sources for final result tables. Internal `moderate_v6`
identifiers remain in the final files because they are frozen into scenario
IDs and artifact hashes.
