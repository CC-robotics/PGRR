# 作业四准备：场景参数—研究问题对照表

日期：2026-08-28

## 1. 目的

新增障碍物或行人不应只是“把环境弄得更难”。每个参数变化都应服务于一个明确问题，并对应预先定义的观察指标。否则即使得到一组数字，也很难形成可解释的论文贡献。

## 2. 候选场景族的研究问题矩阵

| 场景族 | 核心研究问题 | 主要自变量 | 应保持不变的控制项 | 首要结果 | 辅助诊断 |

| 窄走廊对向通行 | 横向空间缩小时，恢复层能否在更少碰撞的同时完成让行/后退？ | 走廊净宽、对向人数、对向速度 | 机器人尺寸、起终点、行人半径、DWB/PGRR 配置 | 碰撞率、到达率 | 最小人距、BACKUP/WAIT 次数、路径长度 |

## 3. 参数设计的原则

### 一次只解释一个主变量

例如研究“走廊宽度”的影响时，行人速度和数量应固定；研究“横穿时间相位”时，遮挡物宽度应固定。可以做多因素设计，但需在实验计划中明确主效应/交互效应，而不是事后解释。

### 难度档要有物理含义

低、中、高不应随意命名。示例：走廊越窄、对向速度越高、相遇时间越接近，均可构成更高风险；但应先检查仍有可通行或合理的恢复空间。

### 不改变比较对象以外的系统

所有方法必须使用相同的地图、起终点、行人轨迹、seed、机器人、DWB 参数、时间限制和终止定义。否则差异无法归因于 recovery method。

## 4. 每一场景族的最小探索顺序

```text
参数纸面检查
  → 单一低难度条件的基础设施 smoke
  → 同一场景族的低/中/高小样本校准
  → 教授确认：保留哪些参数组合与正式重复次数
  → 按锁定的 train / validation / held-out test 计划运行
```

小样本校准阶段的目标是判断“场景是否确实产生预期交互、Base 难度是否合理、日志是否完整”，而不是挑选能让 PGRR 最好看的组合。

## 5. 可写成论文假设、但目前不可当作结论的表述

以下可作为教授讨论后的预注册/研究假设模板：

- H1：在空间更受限的对向交互中，PGRR 相对 Base DWB 能降低碰撞，但可能增加行程时间或路径长度。
- H2：在遮挡后横穿的时序扰动中，触发—掩码—临时恢复链路的安全收益取决于观测到行人的时机和横向逃离空间。
- H3：在短时门口阻塞中，若阻塞会自然消失，有限 WAIT 的代价可能低于强制绕行；这应体现在完成、超时和干预时长的共同报告中。

这些是假设，不能提前写成结果。若新数据不支持，也应如实报告。

## 6. 需要教授拍板的选择

1. 新实验的首要科学问题：空间受限、遮挡突发、群体阻塞，还是多扰动鲁棒性？
2. 新地图是否用于泛化测试，还是先限制在同一地图以控制变量？
3. 哪些终点进入主要统计检验，哪些仅作描述性分析？
4. 新场景是否仅做测试扩展，还是需要独立 train/validation 数据以重新训练 DAgger？

在这四项确定前，我们可以继续做模板、图和日志规范，但不应自行决定正式参数或开始调模型。
