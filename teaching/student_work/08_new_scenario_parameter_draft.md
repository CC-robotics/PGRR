# 新增实验场景：可讨论、可复现的参数草案

> 状态：**草案，不是已确认的实验配置。** 这份表的用途是让我们在与教授交流前，能清楚说明“准备怎么扩展”，而不是直接开始调参或改动冻结基准。

## 共同控制原则

- 保持机器人模型、DWB、PGRR 25 个动作空间、观测定义和终止规则不变。
- 初版继续使用 LiDAR 可见的确定性圆柱行人代理；先控制变量，再考虑更真实的人类意图模型。
- 每个场景都有固定的 `scenario_id`、密度、重复编号和显式随机种子。
- 新数据单独存放，按**场景 ID 和种子**划分训练、验证、保留测试；不使用 `moderate_v6_test` 选模型或阈值。
- 所有比较方法复用完全相同的初始条件，形成 paired comparison。

## 候选场景参数表

| 场景族 | 要研究的困难 | 初版变量（建议取值） | 固定项 | 主要观察指标 |
|---|---|---|---|---|
| 窄走廊对向通行 | 侧向余量不足，是否正确让行/后退 | 走廊宽度：1.4 / 1.8 / 2.2 m；行人数：1 / 2；对向速度：0.4 / 0.8 m/s | 起终点、机器人尺寸、地图坐标系 | 碰撞、到达、超时、让行恢复动作、路径长度 |
| T 路口横穿与遮挡 | 转角后突然出现行人 | 横穿触发距离：1.0 / 1.8 / 2.6 m；遮挡物宽度：0.4 / 0.8 m；行人速度：0.4 / 0.8 m/s | 路口几何、机器人起点与目标 | 最近距离、碰撞、触发延迟、急转/角加速度 |
| 门口群体阻塞 | WAIT、绕行、REPLAN 的取舍 | 门宽：1.0 / 1.4 m；驻留人数：2 / 3 / 4；驻留时间：3 / 6 s | 门位置、行人代理半径、目标位置 | 到达、超时、恢复次数、等待时长、规划失败 |

## 推荐的最小实验顺序

1. 先只做“窄走廊对向通行”和“T 路口横穿遮挡”两个场景族；它们分别覆盖**空间受限**与**感知/时序突变**。
2. 每个场景族先制作低、中、高三个难度档，但先用少量种子完成基础冒烟，不报告论文结论。
3. 确认场景能稳定复位、日志字段完整、Base DWB 具有合理难度后，再由教授确认正式重复次数与划分。
4. 正式实验前，把场景配置、代码提交、随机种子、运行并发和指标计算规则写入新实验 manifest。

## 需要教授确认、目前不自行决定的部分

- 是“同一地图的新交互”优先，还是直接增加新地图来测更强泛化？
- 每个难度/场景族的正式重复次数与统计检验方案。
- 是否把个人空间侵犯等社会导航指标加入论文主指标。
- 新场景是作为训练覆盖扩展、保留泛化测试，还是两者都要并严格分开。
